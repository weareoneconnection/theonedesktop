设置

Anthropic API 密钥

本机运行编程任务需要。密钥用 macOS 钥匙串加密后保存在这台电脑上，不会上传。

OpenAI API 密钥

让 TheOne 引擎使用 GPT 模型（GPT-6 Astra、GPT-5.6）时需要。同样加密保存在本机。

本机运行时

在这台 Mac 上执行任务的 Agent 引擎，只接受本机连接。

执行引擎

任务可以由 TheOne 自己的引擎执行，也可以交给这台 Mac 上的 Claude CLI 或 Codex CLI —— 无论用哪个，工作区快照、改动对比、验证门和审批都还是 TheOne 的。

    已打开的文件夹

    Agent 只能在这里列出的文件夹中接任务。在 TheOne 里用“打开文件夹…”（⌘O）添加。
